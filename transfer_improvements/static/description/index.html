Regenerate Invoice Lines

Made changes to a delivery after creating an invoice? No problem! Click "Regenerate Lines" to rebuild the invoice from current delivered quantities.

Bonus: If multiple draft invoices exist for the same order, they'll be consolidated into one automatically.
