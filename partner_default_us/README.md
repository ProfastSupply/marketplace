# Contact Default Country - US Only

Sets United States as the default and only country option for contacts.

## Features

- ✅ Country field defaults to United States
- ✅ Country dropdown only shows United States
- ✅ State field only shows US states
- ✅ Reduces data entry errors

## Installation

1. Download or clone this module into your Odoo addons directory
2. Update the apps list in Odoo
3. Search for "Partner Default Country - US Only" and install

## Requirements

- Odoo 18.0
- Dependencies: `base`, `contacts`

## Note

This module restricts country selection to US only. If you need US, Canada, and Mexico, 
use the "Partner Default Country - North America" module instead.
