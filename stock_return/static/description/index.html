Stock Return Max Quantities

One-click return all delivered quantities

The Problem

Without This Module

1. Open return wizard

2. Manually set each line to max

3. Click Return

Tedious for full returns

With This Module

1. Open return wizard

2. Click "Return Max Quantities"

 

One click, done!

What It Does

Adds a "Return Max Quantities" button to the stock return wizard that:

Sets all line quantities to their maximum

Immediately processes the return

Opens the new return picking

Two Options

The return wizard now has two buttons:

Return Max Quantities — Returns everything in one click

Return Inputted Quantities — Returns only what you've entered
