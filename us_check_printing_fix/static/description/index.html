US Check Printing - Address Fix

Align check addresses with standard US window envelopes

Key Features

Window Envelope Alignment

Repositions the payee address to show correctly through standard US window envelopes.

Account Number Field

Adds an Account Number field to contacts that prints in the check memo area.

The Problem

The default Odoo US check layout doesn't align the payee address with standard window envelope positions. This module fixes that alignment so you can mail checks without additional address labels.

How It Works

Install and print - no configuration required!

1. Install the module

2. Optionally add Account Numbers to vendors

3. Print checks as normal

4. Address aligns with envelope window automatically

Additional Improvements

Cleaner US address format (no country line)

State shown as code (CA, TX, NY)

Account number in memo field

International addresses still show country
