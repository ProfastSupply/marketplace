# Contact Default Country - North America

Sets United States as the default country and limits selection to US, Canada, and Mexico.

## Features

- ✅ Country field defaults to United States
- ✅ Country dropdown shows US, Canada, Mexico only
- ✅ State field shows states/provinces for the selected country
- ✅ Reduces data entry errors

## Countries Included

| Country | ID | States/Provinces |
|---------|-----|------------------|
| United States | 233 | 50 states + territories |
| Canada | 38 | 13 provinces/territories |
| Mexico | 156 | 32 states |

## Installation

1. Download or clone this module into your Odoo addons directory
2. Update the apps list in Odoo
3. Search for "Partner Default Country - North America" and install

## Requirements

- Odoo 18.0
- Dependencies: `base`, `contacts`

## Note

If you only need United States, use the "Partner Default Country - US Only" module instead.
